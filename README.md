# Việt Craft

Dự án học phần xây dựng website thương mại điện tử cho sản phẩm làng nghề Việt Nam. Repo hiện chứa **thiết kế dữ liệu, API và kế hoạch nhóm**; frontend responsive hiện có cần được đưa vào repo trước khi tạo cấu trúc ứng dụng thực tế.

1. [Kế hoạch và phân công bốn người](docs/TEAM_PLAN.md)
2. [Cấu trúc dữ liệu và ERD](docs/DATA_MODEL.md)
3. [SQL PostgreSQL khởi tạo](database/001_initial.sql)
4. [Hợp đồng API](docs/API.md)

Sau khi đưa code giao diện hiện có vào repo, nhóm bổ sung tại đây lệnh cài thư viện, cấu hình `.env.example`, migration, seed, chạy frontend/backend, tài khoản demo, kiểm thử và triển khai. Trước khi ghép code, cả nhóm cần thống nhất các điểm còn mở ở cuối [TEAM_PLAN.md](docs/TEAM_PLAN.md).
